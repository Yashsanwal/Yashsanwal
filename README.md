<details>
<summary><b>🧩 Multi-Agent Research Assistant</b> — Agentic RAG System with LangGraph, CrewAI & Local LLMs</summary>
<br/>

Architected a multi-agent research pipeline where specialized agents independently handle query decomposition, web retrieval, document ranking, and final synthesis — significantly reducing manual research time. Built on a full RAG stack using a FAISS vector store and Hugging Face embedding models for semantic document retrieval across large private knowledge bases. Deployed entirely locally via OLLAMA / OLLAMA.cpp for CPU-optimized inference and vLLM for GPU-accelerated batched serving, achieving low-latency responses with zero cloud API dependency.
